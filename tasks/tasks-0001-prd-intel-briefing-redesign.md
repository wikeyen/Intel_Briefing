## Relevant Files

### Backend — Foundation
- `pyproject.toml` - Package definition, all dependencies, pytest config (replaces requirements.txt)
- `uv.lock` - Lockfile generated by uv
- `.env.example` - Updated template defaulting to official API endpoints
- `intel_briefing/__init__.py` - Package init; stdout encoding fix lives here only
- `intel_briefing/config.py` - pydantic-settings BaseSettings; env vars override settings.json; safe defaults
- `intel_briefing/models.py` - Shared Pydantic models: IntelItem, IntelReport, SensorResult, HealthResponse, ConfigSettings
- `config/settings.default.json` - Committed default settings structure (no secrets)

### Backend — Pipeline
- `intel_briefing/sensors/base.py` - Abstract Sensor protocol: fetch(config, limit) -> list[IntelItem]
- `intel_briefing/pipeline/collector.py` - Parallel sensor fetch coordinator; per-sensor timeout; sources_ok/failed tracking
- `intel_briefing/pipeline/enricher.py` - Gemini translation + Jina full-content fetch; rate limiting via semaphore
- `intel_briefing/pipeline/dedup.py` - Deduplication logic (case-insensitive title; Politics beats Topics on overlap)
- `intel_briefing/pipeline/cache.py` - Atomic JSON read/write; stale detection

### Backend — Sensors (migrated)
- `intel_briefing/sensors/hacker_news.py` - Ported HN sensor; httpx only; logging
- `intel_briefing/sensors/arxiv.py` - Ported ArXiv sensor; defusedxml; logging; no subprocess pip install
- `intel_briefing/sensors/github.py` - GraphQL sensor activated; BeautifulSoup scraper retired; filename sanitization
- `intel_briefing/sensors/product_hunt.py` - Official API only; Grok hallucination path deleted; centralised secrets
- `intel_briefing/sensors/v2ex.py` - Ported V2EX sensor; defusedxml; fixed type hint; logging
- `intel_briefing/sensors/hn_blogs.py` - Ported HN blogs sensor; defusedxml; HTTP→HTTPS feed URLs
- `intel_briefing/sensors/grok.py` - Ported Grok tech-trends sensor; centralised secrets; logging
- `intel_briefing/sensors/sources_36kr.py` - Ported 36Kr sensor from fetch_news.py; AttributeError guard
- `intel_briefing/sensors/wallstreetcn.py` - Ported WallStreetCN sensor from fetch_news.py
- `intel_briefing/sensors/politics.py` - NEW: X account monitoring via Grok; configurable handles
- `intel_briefing/sensors/topics.py` - NEW: X keyword/hashtag search via Grok; configurable keywords; dedup with politics

### Backend — API
- `intel_briefing/api/main.py` - FastAPI app with lifespan; serves frontend static at /ui
- `intel_briefing/api/routes/intel.py` - GET /intel/latest, GET /intel/{section} with ?limit and ?lang
- `intel_briefing/api/routes/briefing.py` - GET /briefing/markdown
- `intel_briefing/api/routes/config.py` - GET /config (masked), PUT /config
- `intel_briefing/api/routes/control.py` - GET /health, POST /fetch
- `intel_briefing/scheduler.py` - APScheduler AsyncIOScheduler; daily pipeline job; run stats logging
- `intel_briefing/renderer/markdown.py` - Pure string Markdown renderer; no I/O; no HTTP; no sleeps

### Docker & CI
- `Dockerfile` - Python 3.13-slim; uv sync --locked; HEALTHCHECK on /health
- `docker-compose.yml` - backend + frontend (nginx) services; named cache volume
- `.github/workflows/daily-report.yml` - Updated: pytest gate required before report generation; uv install; secure PWA deploy

### Frontend

- `frontend/src/api/client.ts` - Typed fetch wrappers for all backend endpoints

- `frontend/src/pages/Sensors.tsx` - Per-sensor toggles and status
- `frontend/src/pages/Schedule.tsx` - Time picker and timezone selector

- `tests/integration/test_api.py` - All API routes; ?lang=zh; stale flag; 404 on unknown section

### Notes
- Use `uv run pytest` to run tests. Run `uv run pytest -m "not e2e"` to skip live e2e tests.
- Use `uv run uvicorn intel_briefing.api.main:app --reload` for local dev.
- Frontend dev: `cd frontend && npm run dev` (proxies API to localhost:8000).
- All files must start with a 2-line `ABOUTME:` comment per project convention.
- All sensors receive `Settings` via dependency injection — no `os.getenv()` inside sensor files.
